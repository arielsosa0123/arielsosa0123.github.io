# Ariel Sosa's Portfolio

My personal portfolio website presents my background as a computer science student, technical skills, education, certifications, and professional interests.

## Website Features

- **About Me:** A brief introduction to my academic background, interests, and career goals.
- **Education and Skills:** An overview of my university experience, coursework, programming languages, frameworks, and development tools.
- **Resume:** A scrollable resume viewer with zoom controls and a downloadable public copy.
- **Certifications:** CodePath course descriptions and scrollable certificate viewers for AI, web development, and technical interview preparation.
- **Project Access:** A direct link to the CodePath projects available on my GitHub account.
- **Contact Footer:** LinkedIn and GitHub links on every page, plus an email button that copies my address to the clipboard.
- **Responsive Design:** A layout designed for desktop and mobile screens.
- **Custom Animation:** An animated octopus adds personality to the homepage.

## Built With

- React and JavaScript
- React Router
- React-PDF
- HTML and CSS
- Vite
